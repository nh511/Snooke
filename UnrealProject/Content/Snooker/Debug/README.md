Reserved for debug-only Blueprint and visualization assets such as `BP_Debug_Trajectory`.

The UE-facing design uses the standalone names documented in `docs/DEBUG_OPTIONS.md`:
`trajectory`, `collision-points`, `contact-normals`, `sleeping`, and
`physics-steps`. The standalone core implementation is available without UE5;
Developer Settings, console variables, Blueprint controls, and 3D debug drawing
remain pending Unreal Engine 5.8.4 validation.
