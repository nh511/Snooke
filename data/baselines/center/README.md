# Center Strike Baseline

Generated by the Release standalone solver using six-pocket-engineering-v2.
initial.snapshot is stationary; center.input strikes at 0.2 m/s; changed.input
adds 1e-6 m/s and is intentionally expected to differ in comparator tests.
record.shot embeds all parameters/input and the real computed result.
trajectory.csv has 476 rows (475 fixed steps), 57685 bytes, under 1 MiB.
This is an engineering regression, not an empirical cloth calibration.

CTest baseline_center reruns the fixed input and compares every state field
within 1e-9, with exact discrete flags/IDs. It separately reruns the changed input
and requires a FAIL report naming the first differing step, ball and field.
